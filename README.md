# 毛雨晴 · 游戏与交互作品集

独立的游戏与交互求职作品集，原 portfolio-studio 保持不变。

- 首屏公司生存游戏，`dist/game/` 为原单人原型的静态移植。
- 原型来源：用户提供的 new-chat-2/app/page.tsx 与 globals.css；规则与剧情主要由 AI 生成。页面用“AI 协作制作”说明。没有新增个人独立策划、线下测试、多人联机、商业上线等声明。
- 支持项目图片复用自用户已有作品集。
- 默认私有，用户审阅后再决定公开。

## 开发

安装依赖后运行 `npm run build:game` 重建游戏脚本。以 dist 作为静态站点根目录。

## 验证范围

本次已验证游戏脚本编译与语法、所有本地资源引用、首页 HTTP 响应。样式包含连续弹性布局和 1050/760/360 宽度断点，尚未完成跨浏览器、手机实机及完整游戏流程实测。
